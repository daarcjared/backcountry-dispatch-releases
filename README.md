# Backcountry Dispatch

Official downloads and documentation for Backcountry Dispatch, a local radio gateway and Android companion built by Jared Ringenberg.

## Downloads

The first public desktop installers are in preparation. Check [Releases](https://github.com/daarcjared/backcountry-dispatch-releases/releases) for published versions. When a version is available, its **Assets** section is where you’ll find the installer for your platform and the SHA-256 checksums. Read the release notes for supported platforms and radio models.
